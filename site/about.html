The pipeline.

      

        
Lex and parse
An indentation-aware lexer and a recursive-descent parser build the AST, with line and column on every error.

        
Type check
Inference, generics, nullable types, and class inheritance are checked before any code is generated.

        
Own and borrow
Moving a value that is still borrowed is a compile error, so use-after-free cannot reach runtime.

        
Stack or heap
Escape analysis keeps objects that never leave their function on the stack. Only escaping ones are heap allocated.
